# OpenCode WebUI での LaTeX 描画ルール

## 利用可能な記法

- **インライン数式**: `\(...\)` — 正常に描画される
- **ブロック数式**: `\[...\]` — 描画されずプレーンテキストとして表示される
- **ブロック数式**: `$$...$$` — 描画されずプレーンテキストとして表示される
- **インライン数式**: `$...$` — 描画されずプレーンテキストとして表示される

## 対応方針

- 数式は必ず `\(...\)` を使用する
- ブロック数式が必要な場合は、`\(...\)` を使い改行で区切って記述する
- Unicode 数学記号（∂, μ, ν 等）はそのまま表示される
